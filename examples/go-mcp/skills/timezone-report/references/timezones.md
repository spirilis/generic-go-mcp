# Timezones covered by the report

Listed west to east. These are IANA names, which is exactly what the `date` tool's
`timezone` argument takes.

| Region | IANA timezone |
| --- | --- |
| US West | `America/Los_Angeles` |
| US East | `America/New_York` |
| UK | `Europe/London` |
| Central Europe | `Europe/Berlin` |
| India | `Asia/Kolkata` |
| Japan | `Asia/Tokyo` |
